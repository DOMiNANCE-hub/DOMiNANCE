# Quantum numbers and electron capacity

## Learning goals
Apply the allowed values of n, ℓ, mℓ and ms. Calculate shell and subshell capacities and identify invalid sets of quantum numbers.

## Four labels with different roles
The principal quantum number n is a positive integer: 1, 2, 3 and so on. Orbitals sharing n form a shell. Increasing n generally increases spatial extent, but in a many-electron atom orbital energy also depends on subshell and electron interactions. “Same shell” does not mean all orbitals necessarily have identical energies.

For a given n, the angular-momentum quantum number ℓ can be 0 through n − 1. The conventional subshell names are s for ℓ = 0, p for 1, d for 2 and f for 3. A subshell consists of orbitals sharing n and ℓ. Thus 3p is a subshell, while a particular orbital within it is a more specific state.

The magnetic quantum number mℓ takes integer values from −ℓ to +ℓ, including zero. It supplies 2ℓ + 1 orbital states in a subshell. Common real p-orbital drawings are labelled px, py and pz; this is a useful spatial basis, but these labels should not be naively equated one-for-one with the magnetic quantum numbers in every mathematical representation.

The spin quantum number ms has two possible projections, +½ and −½. Electron spin is an intrinsic quantum property. “Clockwise versus anticlockwise rotation about an axis” is not a literal model of a tiny spinning charged ball, and the values are not a continuous range between −½ and +½.

## Worked capacity and validity problems
For n = 3, allowed ℓ values are 0, 1 and 2: 3s, 3p and 3d. Count orbitals as 1 + 3 + 5 = 9. With two electrons per orbital, maximum shell capacity is 18, agreeing with 2n² = 2 × 3². This is a capacity statement, not an instruction to fill every 3d orbital before any 4s occupation.

Consider n = 2, ℓ = 2, mℓ = 0, ms = +½. It is invalid because ℓ cannot exceed n − 1 = 1. For n = 3, ℓ = 1, mℓ = +2, the problem is mℓ: a p subshell permits only −1, 0, +1. By contrast, n = 3, ℓ = 2, mℓ = −2, ms = −½ is allowed. Check each constraint in sequence instead of memorising a few valid examples.

## Misconceptions and scope
An orbital holds at most two electrons, not 2n². A shell can contain several subshells, and a p subshell contains three orbitals rather than three electrons by definition. The lecturer's summary diagram combines values from different subshells; always apply the mℓ range to the selected ℓ, not to the whole shell at once.

## Short concept checks
- How many orbitals and electrons can a 4p subshell accommodate? **Answer:** Three orbitals and at most six electrons; p means ℓ = 1 regardless of n.
- Can a 1p subshell exist? **Answer:** No. For n = 1, only ℓ = 0 is allowed, giving 1s.

## Key takeaways
Shell, subshell, orbital and electron spin describe different levels. Apply the allowed-value rules before counting capacity; a filling sequence requires additional energy and occupancy principles.
