# Functions, dates and common calculations

## Learning goals
Read function syntax, choose a simple calculation, and distinguish a live date function from a typed date.

## A function is a named calculation
A function has a name followed by parentheses containing its arguments. An argument can be a number, text, a reference or a range, depending on the function. =SUM(B2:B5) adds the four referenced cells. Inspect the selected range when using AutoSum; a suggested range still needs checking. These examples use commas as separators; local Excel settings may use a different separator.

## Calculate and explain
| Formula | Result | Reason |
|---|---|---|
| =SUM(4,6,10) | 20 | Adds the arguments |
| =ABS(-4.5) | 4.5 | Returns magnitude without the sign |
| =MOD(17,5) | 2 | Remainder after division |
| =SQRT(81) | 9 | Positive square root |
| =INT(3.8) | 3 | Rounds down to an integer |
| =ROUNDUP(1.234,2) | 1.24 | Rounds away from zero to two decimal places |
A function's result must answer the intended question. A sum describes a total; a remainder describes what is left after whole groups. They are not interchangeable just because both accept numbers.

## Dates are values too
Excel represents dates with serial values and times as fractions of a day, allowing date/time calculations. Use =DATE(2026,10,19) to construct an unambiguous date from year, month and day arguments. TODAY() returns the current date, while NOW() returns the current date and time. Both have empty argument lists and can change when the workbook recalculates; they are unsuitable as a permanent record of the day an event originally occurred.

## Try it
Calculate the total of 4, 6 and 10. Divide 17 items into groups of five and explain both the whole-group count and the remainder. Compare TODAY() with a deliberately entered fixed date.
