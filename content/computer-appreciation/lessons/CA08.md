# Choosing and checking charts

## Learning goals
Match a chart to a question and verify that labels and plotted values mean what you intend.

## Start with data and the comparison
A chart represents selected worksheet data. A data series is a collection of related data points; categories describe the groups or labels. Select the intended data and headings, insert an appropriate chart, then inspect the resulting axes, legend and series. A chart can look plausible while using the wrong range.

## Use the relationship to choose the chart
| Task | Useful starting point | Why |
|---|---|---|
| Compare totals for three departments | Column or bar chart | Compares distinct categories |
| Show weekly counts in chronological order | Line chart | Shows a sequence across time |
| Show one total divided into a few parts | Pie chart | Shows contributions to a whole |
| Compare two numeric measurements for each observation | XY scatter chart | Uses numeric x and y values |
A scatter chart is especially useful when x values are unevenly spaced, such as measurements at days 1, 3 and 10. Place corresponding x and y values in paired columns. A line chart's category positions and a scatter chart's numeric x positions are not the same idea.

## Read before presenting
Check a chart title against its actual selection. Verify units, category labels and whether the legend names the right series. A pie chart uses one series representing a whole; it is a poor choice for several unrelated numeric relationships. Source-linked charts can update when worksheet values change, so recheck a chart after changing its source cells. Saving the workbook preserves an embedded chart with its worksheet.

## Try it
Use fictional counts for three departments to create a column chart. Then use paired day/count observations to create a scatter chart. Explain which variable belongs on each axis and why the two charts answer different questions.
