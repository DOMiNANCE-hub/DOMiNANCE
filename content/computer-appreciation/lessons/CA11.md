# Tables, pictures and presentation objects

## Learning goals
Choose an object that communicates the information, then align, group and order objects intentionally.

## Use the right object
A table organises information into rows and columns. Insert a table, enter a short comparison and add or remove rows and columns when needed. A picture can communicate a visual idea; insert the intended file and inspect its size and placement. Resizing handles change size, whereas dragging the object changes its position. Keep labels associated with the correct visual.
SmartArt provides structured diagram layouts and can turn a list into a diagram. Choose a structure that matches the relationship you want to explain. A diagram format does not prove that its labels or relationships are accurate.

## Position related objects
Alignment places objects along a common edge or centre. The reference matters: Align Top relative to the slide moves objects toward the slide's top; Align Top relative to selected objects aligns their tops with each other. Grouping treats selected objects as a unit so they can move together. Ungroup when individual edits are needed.
Objects also have a stacking order. Bring to Front puts an object above the others; Send to Back puts it behind the entire stack. Send Backward moves it back one layer. If a picture covers a label, inspect stacking order before deleting either object.

## Check multimedia in context
The notes introduce inserting audio and video, sizing a media object and choosing playback options. Test media in Slide Show view on the computer intended for presenting. Confirm that the chosen file plays, the sound can be heard and the timing fits the explanation. Menu locations differ across Office versions; this lesson teaches the task rather than promising identical commands everywhere.

## Try it
Place two labelled shapes on a slide. Align their tops, group and move them, then ungroup. Put one shape behind the other and explain the difference between Send Backward and Send to Back.
