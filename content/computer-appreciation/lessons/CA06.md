# Text, logical tests and financial arguments

## Learning goals
Transform text deliberately, trace IF/AND/OR, and keep financial periods consistent.

## Text operations have a purpose
The & operator and CONCATENATE join text. ="HB"&1 produces HB1. LEN counts characters, LOWER changes letters to lowercase and UPPER changes them to uppercase. LEFT and RIGHT extract characters from the start and end of text. These functions return transformed text; they do not correct the underlying meaning of an identifier or name. Preserve an original column when checking transformations.

## Make a decision explicit
IF has a logical test, a value for a true test and a value for a false test. With a fictional practice score in B2, =IF(B2>=50,"Review complete","Keep practising") returns the first label when B2 is 50 or more, and the second otherwise. This is an exercise threshold, not an institutional pass rule.
AND is true only when all its conditions are true. OR is true when at least one is true. For C1=10, D1=16 and E1=20, =AND(C1>D1,E1>10) is FALSE while =OR(C1>D1,E1>10) is TRUE. Trace each condition before combining them. At B2=50, a >=50 test is true but a >50 test is false.

## Financial functions require consistent periods
The supplied financial section introduces PV (present value), FV (future value), PMT (periodic payment), rate and nper (number of periods). For a five-year loan with monthly payments, nper is 60. If an exercise specifies a nominal annual rate of 12% divided monthly, its period rate is 12%/12. Do not combine a monthly rate with five yearly periods. Cash-flow signs and payment timing also matter; this lesson does not turn an exercise into financial advice.
