# Formatting, printing and workbook care

## Learning goals
Separate appearance from stored values, prepare a readable printout, and save a workbook deliberately.

## Format the display, preserve the value
Number formats control how values appear. They do not normally change the underlying number used in a calculation. A stored value of 0.25 displayed as Percentage becomes 25%; it is still 0.25. Applying Percentage to the stored value 25 displays 2500%, a clue to inspect the input rather than merely changing decimal places. Currency formatting adds a monetary display convention; it does not perform a currency conversion.
Wrap Text makes a long entry appear on multiple lines within a cell. Adjust widths and row heights so headings and data remain readable. Format Painter copies formatting to another selection. These actions serve different purposes from editing a value or copying a formula.

## Check the printed result
Use Print Preview before printing. Page orientation, margins, scaling, print area, and headers/footers affect what reaches the page. Landscape may help a wide table, but forcing a very large sheet onto one page can make its text too small. A print area selects the range intended for printing; it does not delete data outside that range. Check all preview pages for cut-off headings and unwanted blank pages.

## Save and organise
Save updates the current file. Save As lets you choose a new name, location or file type. Save a copy before experimenting with major changes. Rename worksheets so their purpose is clear and verify which sheet is active before editing or deleting it. Workbook structure protection concerns operations such as adding sheets, whereas sheet protection concerns permitted edits within a sheet. File encryption is a separate option; do not treat every protection command as equivalent.

## Try it
Format 0.25 as a percentage and inspect its value in the formula bar. Prepare a print area for a small fictional table, preview it, and save a separately named practice copy.
