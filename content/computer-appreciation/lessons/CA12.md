# Presenting, printing and controlled effects

## Learning goals
Choose an appropriate view, distinguish animations from transitions, and rehearse the saved presentation.

## Choose a view for the task
Normal view is for creating and editing slide content. Slide Sorter shows slide thumbnails, making it useful for checking the overall order and dragging slides into a new sequence. Slide Show presents the slides as the audience sees them. Inspecting a deck in editing view alone does not reveal every playback or timing problem.
In Slide Show, navigation keys such as the arrows, Page Down and Enter move through slides; Escape ends the show. Rehearse the sequence and test how each slide advances rather than assuming that it waits for a click.

## Animation is within a slide; transition is between slides
An animation acts on text or another object on a slide. A transition affects the change from one slide to the next. To reveal three points one at a time, work with object/text animations. To apply an effect when a new slide appears, use a transition. Review order and timing after changing effects. Applying an effect to all slides should be an intentional choice.
The lecturer notes mix commands from older Office interfaces with Office 2016 terminology. Use the Animations controls for object effects and the Transitions controls for between-slide effects in current ribbon interfaces. The conceptual distinction is the assessed objective, not a memorised legacy tab location.

## Check delivery and printed output
Use Print Preview to choose the intended print output, page range, colour mode and number of copies. Handouts support an audience; the editable deck supports further revision. Preview every selected page rather than assuming the on-screen layout will print identically.
Reopen the saved presentation, use Slide Sorter to check order, run Slide Show, test media and transitions, and inspect the print preview. These checks validate delivery, not the academic truth of slide content.

## Try it
Rehearse a three-slide deck. Add one object animation and one between-slide transition, identify each, and confirm that Escape exits the show. Remove any effect that gets in the way of the explanation.
