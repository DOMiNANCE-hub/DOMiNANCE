# Formulas, references and evaluation order

## Learning goals
Write a formula, predict a copied reference, and explain why parentheses change a result.

## Build a calculation
Use = to begin formulas in these lessons. With quantity in B2 and unit price in C2, =B2*C2 calculates the row cost. The cell normally displays the result; the formula bar shows the formula. Changing an input recalculates dependent formulas under normal automatic calculation.
Multiplication uses *, division / and powers ^. Multiplication and division have equal precedence and are evaluated left to right; addition and subtraction also share a precedence level. Parentheses make the intended grouping explicit. Thus =6+27/3 gives 15, while =(6+27)/3 gives 11. =10/5*2 gives 4, whereas =10/(5*2) gives 1.

## Decide which references may move
| Reference | Fixed part | When copied one column right and one row down |
|---|---|---|
| B2 | Neither | C3 |
| $B$2 | Column and row | $B$2 |
| $B2 | Column | $B3 |
| B$2 | Row | C$2 |
For a shared rate in F1, =B2*$F$1 copied down becomes =B3*$F$1. Only the row-specific quantity moves. When editing a reference, F4 cycles through reference types on supported keyboards.

## Read and diagnose formulas
A colon denotes an inclusive range: B2:B5 includes four cells. An exclamation mark separates a sheet name from a cell, as in ='Stock List'!B2. An ampersand joins text, as in =A2&" "&B2. A formula in D3 that refers to D3 depends on itself and creates a circular reference. Check the intended input range rather than treating that as ordinary addressing.

## Try it
Predict =B2*$F$1 after copying one row down. Then compute the four evaluation-order examples before checking them in Excel.
