# PowerPoint slides, layouts and saved files

## Learning goals
Distinguish a presentation, layout and theme, then create and save a short deck.

## Build a presentation from slides
PowerPoint is presentation software. A presentation contains slides; each slide communicates part of the overall explanation. Start with a blank presentation or a template, then add the slides you need. A template is a starting document; review its existing content before using it.
A layout arranges placeholders for a slide's content. A Title and Content layout provides a title placeholder and an area for content such as text, tables or pictures. Changing a layout changes the arrangement; it does not automatically supply academically correct content. Insert, copy, reorder or delete slides deliberately and check that the resulting sequence still makes sense.

## Separate arrangement from appearance
A theme is a predefined combination of colours, fonts and effects that can be applied to a presentation. It promotes visual consistency across slides. Layout answers “where does content go?” while theme answers “what coordinated appearance does it use?” Text boxes add text beyond a layout's placeholders. Bullets present parallel points; numbered lists make order explicit.

## Save a usable file
Save As selects a name, location and format; subsequent Save updates the current file. The .pptx format keeps a normal editable presentation. A .ppsx PowerPoint Show is intended to open in Slide Show view. A PDF is useful for a fixed-layout copy, but is not a substitute for the editable deck when someone needs to revise slides. Check the saved file and keep the working presentation.

## Try it
Create a three-slide explanation of a fictional study routine: purpose, steps and recap. Choose layouts to fit each slide, apply one theme, save as .pptx and reopen it. Confirm that the file you reopened is the editable presentation.
