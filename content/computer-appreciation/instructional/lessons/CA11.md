## A labelled comparison slide
Create a fictional comparison using a two-column table: Method and Purpose. Insert a table with a heading row and two example rows. Enter the headings, then move between cells using the source-described navigation. In the target software, verify where the insertion point is before adding a row or column.

1. Select a row that needs a new row before it. The lecture's Insert Above adds a row relative to that selection; it does not add a new slide.
2. Select the relevant column and compare Insert Right with Insert Above. One changes columns, the other rows. Merging cells cannot substitute for adding a missing column.
3. Insert a picture and a separate text label. Move the picture by dragging the object; compare that with using a sizing handle to change its size.
4. Check proportions after resizing. The source warns that side handles can distort the aspect ratio. A border adjustment changes a surrounding line, not the underlying picture's proportions.

## Alignment, grouping and stacking solve different problems
Select two labels whose top edges should line up with each other. Choose alignment relative to the selected objects before Align Top; alignment relative to the slide answers a different positioning question. Group related objects when you need them to move as a unit, then verify their relationship has stayed intact.
If the picture covers a label, inspect stacking order. Send Backward moves one level toward the back, whereas Send to Back moves behind the entire stack. Grouping does not automatically correct every overlap, and changing the slide theme does not bring a hidden label to the front.

| Problem | Relevant operation |
|---|---|
| Two top edges differ | Alignment and its reference |
| A picture covers a label | Front/back stacking |
| A diagram's parts must move together | Grouping |
| A border is too thin | Picture Border Weight |
| An inserted sound is too loud | Volume, not loop or icon visibility |

## Media requires a delivery check
An inserted audio/video icon establishes the presence of an object, not successful playback on another computer. Test the saved presentation in Slide Show on the intended machine, check sound and verify that required media are available. No such Microsoft Office audio/video acceptance was performed here. Treat a playback problem as a delivery issue requiring observation, not something proven fixed by hiding the icon or changing the border.
