## Compare a search, a position and an orientation change
Draw a fictional register with identifiers down the first column and prices beside them. Finding a key down that column and returning a value across its row matches the lecturer's VLOOKUP description. In a separate table with keys across its top row, the corresponding horizontal direction matches HLOOKUP.
These descriptions identify a family and direction. They are not a complete exact/approximate-match tutorial; the brief source glossary does not supply enough evidence to invent all argument defaults or data-order requirements.

| Intended result | Relevant glossary idea |
|---|---|
| Return a related value after searching the first column | VLOOKUP |
| Return a related value after searching the top row | HLOOKUP |
| Return a matching position | MATCH, with the labelled technical clarification |
| Select a value using an index | INDEX |
| Exchange row and column orientation | TRANSPOSE |
| Return an address as text | ADDRESS |

## A position is not the value stored there
In the checked fictional example B2=4 and B3=6. MATCH(6,B2:B3,0) returned 2 in the alternative engine: the target is the **second item of the selected range**. The returned position is neither the matched value 6 nor the worksheet row number 3.
Keep this clarification distinct from the lecturer's terse MATCH wording. It supports reasoning about relative position but does not certify desktop Excel operation, introduce a complete lookup specification or claim lecturer approval.
If the task instead asks for the orientation to change, a search function does not solve it merely by containing “LOOKUP” in its name. TRANSPOSE concerns row/column arrangement. Similarly, ROW/COLUMN identify positions, whereas ROWS/COLUMNS count a range's dimensions.

## Design a troubleshooting explanation
A learner says, “MATCH returned 2, so the price must be 2.” Ask what output was requested. A location within a range and a related value are different result types. Sketch the small range and number its entries from the start to make the error visible.
Check: why can the correct function family still be insufficient for a working spreadsheet? The chosen range, arguments and intended matching behavior must also be specified and reviewed. That detailed source-grounded tutorial is a remaining content gap, not silently completed by this glossary lesson.
