## Make the source of a custom sequence explicit
Use an original fictional cycle: Lecture, Tutorial, Practical, Revision. The desired pattern is categorical order, not numerical increase. Begin in an empty practice area and decide whether the ordered entries already exist in worksheet cells.

| Situation | Workflow described in the source | What to inspect |
|---|---|---|
| Entries already in cells | Select/check the cell range and Import | Correct cells and order |
| Entries need typing | NEW LIST, type entries, then Add | One intended item per entry |
| Need to use a stored sequence | Select an appropriate seed and fill | Resulting labels and repetition |

For the import case, place the four labels in A1:A4, select them and inspect Import list from cells before choosing Import. For the typing case, choose NEW LIST, enter the labels in order and choose Add. Add stores typed entries; NEW LIST starts that entry workflow. Those are different stages, so choosing NEW LIST alone does not demonstrate that a completed list was stored.

## Predict a cycle and troubleshoot it
If the intended cycle starts at Tutorial, predict Tutorial, Practical, Revision, Lecture as it continues. Compare it with repeatedly copying the single label Tutorial. Both are possible outputs, but only one expresses the specified cycle. If a fill produces repeated labels, inspect whether the custom list was created and whether the intended fill operation was selected; do not assume the pattern was inferred from one unfamiliar word.
If imported entries appear in the wrong order, inspect the worksheet range and its current contents. Reformatting destination cells does not repair a stored ordering mistake. Check numeric-looking labels separately: the notes distinguish direct text/mixed entries from a numeric-only list first prepared as text in cells. Do not turn that source-specific workflow into a claim that numeric data can never be used in a series.

## Practical boundaries and concept check
Exact Options routes differ across the mixed legacy examples. Use the installed version's Custom Lists feature and retain the saved practice file; the required Excel GUI acceptance is still unexecuted.
Explain why this exercise is not AutoComplete. AutoComplete suggests a repeated text entry while typing; a custom fill list supplies an explicitly ordered sequence used by filling. A worksheet can contain the same words in both demonstrations while the mechanisms remain different.
