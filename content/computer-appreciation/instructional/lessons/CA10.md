## Build a three-slide explanation deliberately
Use an original fictional topic, “How our study group prepares a session”. Decide the communication purpose of each slide before choosing its appearance.

1. Create a new presentation. Add a title slide naming the purpose, then a Title and Content slide for the ordered preparation steps, followed by a recap slide.
2. Enter a short title and content in the placeholders. Use numbering for sequential actions and bullets for parallel recap points; a list's visual structure should match its meaning.
3. Apply one theme and inspect all slides. A theme coordinates fonts/colours/effects; it does not determine whether the order or academic explanation is correct.
4. Change a slide's layout to compare its placeholder arrangement. Contrast that with changing the theme: content positioning and coordinated appearance are separate decisions.
5. Save the editable presentation as a practice .pptx, reopen it, and verify that you can select and revise individual objects. Preserve that file when making any fixed-layout output copy.

## Text alignment is not object positioning
Place a small text box near the left edge of a slide. Center its text. The text is centred **inside the box**; the box itself has not been moved to the centre of the slide. A title placeholder and a separate text box can use the same text-formatting commands while remaining different containers.
For a continued numbered procedure, use the source's Start at setting to request the intended starting number. Changing font size, line spacing or the slide number does not change the list's starting value. Menu names and dialog routes must be checked in the installed version.

## Troubleshooting and file comparison
If a new theme gives unexpected background choices, inspect its theme colours rather than assuming that the file name controls backgrounds. If a collaborator receives only a PDF or image, they may see the material but lose the normal object-editing workflow. Keep the .pptx and send an appropriate output copy for the intended purpose.
Check: a slide looks consistent but its steps are in the wrong order. Would applying another theme fix that? No; revise the content sequence. These are source-aligned practical instructions, not evidence that PowerPoint's pending desktop scenarios have been executed.
