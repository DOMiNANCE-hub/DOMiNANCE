## A percentage error you can diagnose
Enter 0.25 in A2 and 25 in A3. Apply Percentage to both and compare the displayed 25% and 2500%. Inspect the formula bar: the stored inputs still differ by a factor of 100. Changing the number of displayed decimal places cannot correct a value entered in the wrong scale.
Write the intended input convention above the column. If the value represents a fraction of one, 0.25 corresponds to one quarter. Formatting describes how that value is presented; multiplying a wrong input by a display convention does not validate its meaning.

## Prepare a small table for output
1. Create a fictional table with one heading row and several records. Wrap long headings and inspect column widths; do not merge unrelated records merely to fit a title.
2. Select the intended output range and define its print area using the source-described print settings. The rest of the worksheet should remain available for editing.
3. Inspect Print Preview page by page. Compare portrait and landscape for the table's shape, then inspect margins and scaling.
4. If forcing one page makes text unreadable, revise the layout or allow additional pages. “Fits” and “readable” are different requirements.
5. Confirm the selected sheet, range and copy count before printing. Save a separately named practice copy before experimenting further.

## File choices and protection boundaries
Save normally updates the current destination; Save As lets you choose another name, location or type. Renaming a worksheet tab changes its label inside a workbook, not the workbook file's destination. Reopen the intended saved file rather than inferring success from its on-screen title alone.
Keep protection concepts separate. Restricting worksheet edits is different from restricting workbook structure, and both differ from encrypting a file. Do not test protection on an irreplaceable original or assume a protected sheet is confidential storage. The Office protection dialogs remain unexecuted; this comparison does not establish target-version acceptance.

## Check your understanding
A table's total is correct, but the printout omits its last column. Explain why recalculating the total cannot fix the selected print range or scaling. Conversely, an attractive printout does not establish that the underlying quantities or formulas are correct.
