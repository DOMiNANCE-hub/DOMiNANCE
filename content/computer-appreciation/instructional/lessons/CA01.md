## Worked register: labels, inputs and a result
Build this original exercise in a new practice workbook, using fictional equipment rather than patient information. Its purpose is to make the difference between an identifier, a quantity and a calculation visible.

| Cell | Entry | Meaning |
|---|---|---|
| A1 | Item ID | Column label |
| B1 | Quantity | Numeric input heading |
| C1 | Unit price (GHS) | Unit belongs in the heading |
| D1 | Cost (GHS) | Calculated output heading |
| A2 | '0017 | Text identifier, displayed as 0017 |
| B2 | 4 | Four items |
| C2 | 12 | Twelve GHS per item |
| D2 | =B2*C2 | Expected result 48 |

1. Select each address before entering its value. Use the Name Box to check your location if the grid is unfamiliar.
2. Enter the headings, then the identifier and two numeric inputs. The apostrophe distinguishes the identifier from a number; it is not part of its displayed label.
3. Enter the formula in D2. Inspect D2 in the formula bar: the formula and its displayed answer serve different purposes.
4. Change B2 from 4 to 5 and accept the edit. The expected cost becomes 60 under normal automatic calculation. This is an input change, not a formatting change.
5. Begin changing C2 to 99, but press Escape before accepting it. Reinspect C2 and the cost: cancelling that edit should preserve the previously accepted price.

## Troubleshoot the meaning before the appearance
If the cost cannot be calculated as intended, inspect whether the price was entered as the text “12 cedis” rather than numeric 12. Making text look like currency does not supply a numeric input. If the identifier displays as 17, ask whether it was entered as a number before applying a new format; a display choice and storing an identifier as text are different solutions.
If a value appears in the wrong row, correct its location before calculating. A correct multiplication of the wrong record's inputs remains the wrong equipment cost.

## Check your understanding
Why is adding two item identifiers meaningless even when both contain digits? They are labels for records, not measured quantities. Why does changing quantity alter the cost? D2 depends on B2 through its formula. Being able to explain those relationships is more useful than reproducing the table without understanding it.
