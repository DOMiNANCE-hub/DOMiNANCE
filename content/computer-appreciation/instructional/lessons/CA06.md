## Trace a decision rather than memorising a label
Use fictional scores 49, 50 and 51 in B2:B4. Enter =IF(B2>=50,"Review complete","Keep practising") beside the first score and copy it down with the row reference relative. Inspect both the copied formulas and outputs.

| Score | Score >=50 | IF output |
|---|---|---|
| 49 | FALSE | Keep practising |
| 50 | TRUE | Review complete |
| 51 | TRUE | Review complete |

The text labels are branch outputs; IF does not return the number merely because it tested a number. Changing >= to > changes only the boundary case here. The threshold belongs to this exercise, not an official academic rule.
For two conditions, write their individual truth values first. If one is false and the other true, AND is false because both are required; OR is true because at least one succeeds. Do not confuse “at least one” with “exactly one”: OR also remains true when both conditions are true.

## A transparent text transformation
Keep an original label in A2 and use a separate output cell for =UPPER(A2). Compare the result with =LOWER(A2), then use ="HB"&1 to build HB1. Joining text creates a label; it does not add the number 1 to HB. Preserving the original lets you identify unintended changes before replacing any source data.
When a numeric-looking identifier is transformed, ask whether its text representation and leading zeros remain meaningful. Text functions cannot decide whether two differently written identifiers refer to the same real record.

## Match financial units before calculating
An exercise specifies five years of monthly payments at a nominal 12% annual rate divided monthly. There are 5*12=60 periods; the stated monthly rate is 0.12/12=0.01, or 1%. Record those units next to the inputs before choosing PV, FV or PMT.
Using 12% with 60 monthly periods would apply the annual figure as though it were a monthly rate. Using the monthly rate with nper=5 would model five months, not five years. These are model errors even if the function accepts the arguments. Cash-flow signs and timing need their own specified assumptions; no official payroll or loan answer is inferred here.
