## A controlled fill experiment
Use an empty area so that the experiment cannot overwrite valid records. Predict each output before executing the source-described operation.

1. Enter 2 in A1 and 4 in A2. Select **both** seed cells. Extend the fill handle through A5 and inspect each value: the intended arithmetic series is 2, 4, 6, 8, 10.
2. In C1 enter a single label, Lecture. Copy it through C3 with the fill handle. A repeated label does not demonstrate a numeric pattern.
3. In E1 enter Lecture. Begin typing the same label in E2 and observe any AutoComplete suggestion. Here typing into a column prompts a text suggestion; dragging a selection into neighbouring cells is AutoFill.
4. Inspect the destination immediately. If the outcome is a copy rather than the intended series, inspect the selection and fill options. Do not repair a misunderstanding by repeatedly dragging farther.

| Observation | Explanation to test |
|---|---|
| 2, 4, 6, 8 | A two-seed arithmetic pattern adds 2 |
| 2, 4, 8, 16 | This is doubling, not the stated arithmetic pattern |
| Lecture repeated | Copying a label can be appropriate |
| A typed existing label is suggested | AutoComplete, not a new numeric series |

## Clearing versus deleting a whole record
Create three fictional rows with an ID and a count. Clear the middle count: the identifier stays in its row and the count cell becomes empty. In a separately saved copy, delete the entire middle row: the lower record moves up as a complete row. Deleting just one cell with a shift can separate fields that should describe the same record.
This distinction explains why clearing is suitable for an unknown measurement, whereas deleting a complete duplicate record is a different decision. Neither action should be chosen solely because it makes an unwanted display disappear.

## Recovery and self-check
After an unintended fill, use Undo while the operation can still be reversed; inspect the original and target ranges before trying again. Saving first is not a recovery method. Changing a number format cannot restore overwritten contents.
