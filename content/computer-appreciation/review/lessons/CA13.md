# Custom fill lists

## Learning goals
Distinguish a custom sequence from AutoComplete and choose between importing and typing a list.

## A sequence you define
AutoComplete suggests an existing text entry in a column. A custom fill list defines a reusable order, such as Lecture, Tutorial, Practical, Revision. This fictional example illustrates the lecturer's custom-series concept; it is not an official timetable. The source describes text or text mixed with numbers. It says numeric-only items should first be entered in cells formatted as text.

## Import or create
If the items already occupy worksheet cells, select the intended range, open Custom Lists, check the Import list from cells range, and choose Import. Verify the stored order before using the fill handle.
If the items are not in cells, choose NEW LIST, type one entry per line in List entries, and choose Add. NEW LIST selects the creation workflow; Add stores the typed entries. Import reads an existing worksheet range instead.

## Check the interface rather than memorising one path
The notes mix Advanced/General and older Popular routes to Custom Lists. Exact menu labels depend on the installed version. The concept being tested here is selecting a source range versus entering the ordered items manually. The Windows Excel workflow has not been executed in this environment.

## Apply it
Start a four-item fictional custom sequence from its second item and predict what should follow. Compare the result with a copied single label. Do not overwrite an existing destination range merely to test a sequence.
