# Named cells and ranges

## Learning goals
Explain why names help formula reading and distinguish defining, selecting and managing a name.

## Names express meaning
The source contrasts Price * Quantity with A1*B1. A meaningful name can make a formula easier to interpret, but its reference must still point to the intended cells. Naming an incorrect selection does not correct its data.
The lecturer's basic starting-character rule allows a letter or underscore and excludes spaces. A short example such as _Price follows that rule. This is an illustration of the stated rule, not an exhaustive specification of every name Excel permits.

## Locate and inspect
The Name Box is at the left end of the formula bar. It can show an active cell address or the name of a selected range. Its list can also select defined names. The source describes selecting cells, entering a name in the Name Box and pressing Enter to define it.
Name Manager provides a place to add and manage several names. Inspect both the name and its Refers To selection. The source contrasts creating one name through Define Name with returning to Name Manager to add more.

## Apply it
For a fictional table, name the unit-price cell Unit_Price and the quantity cell Quantity. Write =Unit_Price*Quantity, then explain which two original cells it reads. Change one input and inspect the result. This exercise tests reference meaning; it does not establish an official naming convention or prove that a desktop UI has been tested.
