# Print titles, headers and manual page breaks

## Learning goals
Distinguish repeated page information from worksheet data and place a manual page boundary deliberately.

## Print settings answer different questions
The Sheet tab described in the lecturer notes includes print area, print titles and page order. A print area limits which range is intended for output. Print titles concern repeated headings across pages; they do not add new source records. Headers and footers can add a title, date, page number or other text at the top or bottom of each printed page.
These features should support interpretation. A reader should be able to identify columns and page sequence without mistaking a printed heading for another observation.

## Manual boundaries
A page break marks where one printed page ends and another begins. The source says manual breaks override automatic breaks and cause automatic boundaries to reposition. To put a horizontal break after a chosen row, its example places the active cell below that row before inserting the break. A vertical break is placed to the right of the intended column.
Changing a break changes pagination, not the values in the worksheet. Preview the output again after changing a break, print area, orientation or scaling. Menu paths in these legacy notes differ between versions; the questions assess the relationship rather than claim one universal UI route.

## Apply it
For a fictional multi-page list, identify which headings should repeat, choose page numbering, and place a break between two intended groups. Explain why a worksheet can be correctly calculated but still poorly printed. The headless print-export evidence is an alternative renderer check, not certification of Excel's Print Preview workflow.
