# Consolidating worksheet data

## Learning goals
Identify source and destination ranges, and distinguish a fixed summary from a linked result.

## Bring comparable data together
Consolidation gathers data from several source ranges into a master worksheet or summary. The lecturer uses sales data from January, February and March. It is not merely pasting entire worksheets below one another; the source ranges and chosen aggregation must represent the intended comparison.
For a fictional example, monthly totals of 12, 15 and 23 consolidate by SUM to 50. This arithmetic example illustrates the mechanism; it does not reproduce an institution's financial records.

## Sources, destination and function
The destination is where combined results appear. The source ranges supply the inputs. The described Consolidate dialog adds source ranges through Reference and Add, then applies a selected function. Check that category labels and positions match the operation before accepting the output.
A total can be arithmetically correct and still combine the wrong categories if source selections are wrong. Inspect an individual category in the contributing worksheets rather than trusting only the grand total.

## Fixed or linked
The source explicitly offers fixed values or links that update when sources change. A fixed result is a snapshot; changing a source does not imply that a fixed snapshot will recalculate. A linked result may reflect subsequent input changes. The actual Excel dialog workflow has not been executed here.

## Apply it
Make a three-source fictional summary and state the destination, input ranges and aggregation function. Explain which output you would choose for a fixed archived snapshot and which for a changing working summary.
