# Lookup and reference glossary

## Learning goals
Choose a function family from the relationship being described without inventing a complete lookup specification.

## Read the direction of the search
The source table describes VLOOKUP as looking down the first column and moving across the row to return a value. HLOOKUP looks across the top row. These are different search directions; a sheet's visual orientation should guide the choice.
A fictional register with identifiers in its first column suggests a vertical lookup. A table with its lookup keys along the first row suggests a horizontal lookup. The lecture's glossary is not a full tutorial on exact/approximate matching or every argument, so those behaviors are not inferred here.

## Position, value and orientation
MATCH concerns a matching position, whereas INDEX selects a value from a reference or array using an index. TRANSPOSE switches rows and columns. ROW/COLUMN describe position; ROWS/COLUMNS count dimensions. These names look similar but answer different questions.
Technical clarification: the source's MATCH entry only says that it looks up values in a reference or array. The position interpretation is more specific than that wording. A local headless calculation of MATCH(6,B2:B3,0), with B2=4 and B3=6, returns position 2. This alternative-engine check supports the explanation; it does not constitute Excel desktop acceptance or lecturer sign-off.
The table also describes ADDRESS as returning an address as text and INDIRECT as resolving a reference indicated by text. A text label that looks like an address is not automatically a cell reference in every formula.

## Apply it
Draw a fictional two-column table and a separate top-row table. Identify the search direction for each before choosing a function. Explain why rearranging rows into columns is a TRANSPOSE task rather than a VLOOKUP task. Detailed lookup syntax and practical Office execution remain later review work.
