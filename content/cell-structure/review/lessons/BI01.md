## Work an explicitly supplementary absorbance example
If incident intensity I0=100 units and transmitted intensity I=10 units, A=log10(100/10)=1. If I=1 with the same I0, A=2. The logarithmic scale means a tenfold change in transmitted fraction is not merely an additive ten-unit intensity change.
Under suitable Beer–Lambert conditions, halving concentration while holding path length and molar absorptivity fixed halves absorbance. For an original example A=0.8 before a twofold dilution, the predicted diluted value is 0.4. This equation-based example remains labelled supplementary: the lecturer's instrument pages focus on wavelength selection and measured intensity, not an explicit proof of Beer–Lambert.
